# Security policy

CorvusAI is experimental software and should not be trusted to execute unreviewed code.

Do not run generated code on the host without isolation. Do not load checkpoints
from untrusted sources; serialized model files may be unsafe.

For security vulnerabilities, use GitHub's private vulnerability reporting feature
(if enabled) or contact a maintainer privately. Avoid public exploit details until
a fix is available. There is currently no guaranteed response SLA.
