# CorvusBrain V1.0 — First usable local shell

CorvusBrain V1.0 provides an **interactive local code-completion interface**
that loads the checkpoint only once. It runs on CPU or CUDA, does not call
external model APIs, and supports byte-level and BPE checkpoints.

It is an experimental first usable **interface**, not a trained,
general-purpose coding assistant. No pretrained weights or production-quality
code generation are included. You must train or supply your own trusted
local checkpoint and, for BPE, its matching tokenizer.

## Installation

On Windows with Python 3.11:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

## Interactive mode

```powershell
.\.venv\Scripts\python.exe -m corvusai.inference.brain --checkpoint checkpoints/bpe/latest.pt --tokenizer checkpoints/tokenizer.json --device cuda --max-new-tokens 80
```

Type a Python prompt and press Enter. Use `/quit`, `/exit`, or Ctrl+C
to leave. For byte-level checkpoints, omit `--tokenizer`. To run without
CUDA, use `--device cpu`.

## One-shot mode

```powershell
.\.venv\Scripts\python.exe -m corvusai.inference.brain --checkpoint checkpoints/bpe/latest.pt --tokenizer checkpoints/tokenizer.json --device cpu --prompt "def add(a, b):" --max-new-tokens 80 --seed 42
```

The output includes the original prompt. Each interactive request is
independent, with an incrementing random seed. The shell is **not**
a conversational assistant and does not remember prior prompts.

**Security:** Only open trusted local checkpoints. Generated code is
untrusted and must not be executed without inspection and isolation.
The shell does not execute generated code.

**Performance:** Model weights remain resident across prompts, reducing
repeated checkpoint loading. Generation still recomputes attention over
the context at every token; there is no KV cache yet. No throughput or
accuracy benchmark is claimed.
